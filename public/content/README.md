# Public content

This directory mirrors the archive's public site areas. Keep only browser-requestable assets here; catalog inputs, OCR output, transcripts, and unpublished source scans belong in `data/`.

- `audios/`: artwork for `/audios` records.
- `videos/`: artwork for `/videos` records.
- `written/books/`: published book PDFs and matching thumbnails.
- `written/newsletters/`: newsletter PDFs and matching thumbnails.
- `quran/organized_appendices/`: the canonical appendix tree, grouped by edition year.

Appendix PDFs use stable `appendix-N.pdf` names. The 1981 edition remains a single `appendices.pdf` because splitting its image-heavy scan multiplies storage without adding content; its catalog records point to the relevant start pages. The 1989 and 1992 editions use one PDF per appendix.
