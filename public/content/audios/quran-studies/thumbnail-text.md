# Quran Study Thumbnails — Extracted Text

Verbatim text transcribed from each of the 52 thumbnail images in
`thumbnails/`, read directly from the images (not inferred from
filenames — several filenames do not match their actual image text,
notably files 35 and 36, which have swapped content).

Line breaks below reproduce the line breaks shown on each slide.

## Shared background color

`#026634` (RGB 2, 102, 52) — confirmed by sampling the single most
frequent pixel across the full image, not just a corner, on multiple
files; it accounts for ~90% of all pixels in a typical thumbnail. This
is the color of every one of the 52 files to within ordinary JPEG
compression noise (a couple of files sample at `#016833` or `#026533`,
one pixel-value off). The one PNG master file (52) samples very
slightly different at `#046434`, the same design color re-exported.

## Shared font

A bold, high-contrast serif (thick stems, thin bracketed serifs,
double-story "a", classic "Q" with a diagonal tail through the bowl) —
consistent with **Times New Roman Bold** (or a metric-equivalent such
as Liberation Serif Bold). This is a visual match based on the
letterforms in the highest-resolution source (file 52); it is not a
programmatic font-fingerprint match, since no font-identification tool
was available.
