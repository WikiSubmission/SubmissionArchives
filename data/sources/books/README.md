## Transcription policy

Every PDF page is represented, including covers, blank pages, Arabic facsimile pages, tables, diagrams, and back matter. Embedded text is preferred where reliable. Scanned pages retain raw OCR in JSON and receive a conservative cleaned reading transcription. Quranic Arabic is normalized to verified Unicode only when the printed reference or a strong OCR match supports it. Other Arabic remains explicitly flagged rather than guessed.
